## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the code.

## Data and privacy

Equipment, member, activity, and settings data are stored in the current browser's local storage. They are not committed to or uploaded to GitHub, and they are not shared between browsers. The GitHub repository is private, which restricts access to the source code to invited collaborators.

Google Sheets sync currently requires a link-accessible sheet. CSV files can also be imported. Private-sheet access would require Google authentication and a secured backend.
